# Fwza Utility — Releases

Download and update feed for **Fwza Utility**, a Windows tweaking and
optimization tool.

**[⬇ Download the latest installer](../../releases/latest)**

Grab `FwzaTweakingUtility-win-Setup.exe` from the latest release.

---

## Installing

1. Run the installer. It installs per-user — no administrator prompt.
2. Fwza updates itself automatically. When a new version is ready you'll see a
   notice inside the app; click **Restart now** to apply it.

## Requirements

- Windows 10 version 2004 or newer, or Windows 11
- 64-bit (x64)

No .NET installation required — the runtime ships inside the app.

## Note on SmartScreen

New releases have no download reputation yet, so Windows SmartScreen may warn on
first run. Choose **More info → Run anyway**.

---

## About this repository

This repo contains **published release packages only** — no source code. It is
public so the app can fetch updates without embedding a GitHub token in the
binary, which anyone could extract.

Application source lives in a separate private repository.
